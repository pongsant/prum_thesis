# Gen X Soft Club homepage

Research: https://cari.institute/aesthetics/gen-x-soft-club

Applied cues: restrained urban minimalism, muted olive and gray-green, soft abstract interference patterns, light Helvetica Neue with Helvetica/Arial fallbacks, and small utilitarian labels. Existing CD navigation and all track links are preserved.

Current artwork: original CSS radial gradients, elliptical contour patterns, and subtle procedural grain in `dist/styles/home.css`. No photographic image is used on the homepage. The earlier generated transit image is retained as an unused asset.
